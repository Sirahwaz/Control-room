# Security Policy

## Scope

This community package is a static demonstration and documentation set. It does not contain production credentials or connect to production systems.

## Reporting

Do not publish secrets, personal data, exploit details, or sensitive infrastructure information in public issues. Contact the project maintainer privately through the GitHub profile for this repository and provide a concise description and safe reproduction steps.

## Public-demo rules

- Never add secrets or tokens to the repository.
- Never add real customer, wallet, or account data.
- Never add production API endpoints or internal hostnames.
- Keep examples synthetic and non-sensitive.
- Report suspected exposure promptly; rotate any credential that may have been exposed.
