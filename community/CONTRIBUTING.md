# Contributing

Thank you for helping improve the MIDAD AI Community materials.

## Good first contributions

- Clarify documentation and installation instructions.
- Improve mobile accessibility and semantic HTML.
- Add diagrams or examples using synthetic data.
- Report reproducible defects in the static demo.
- Improve translations while preserving technical accuracy.

## Contribution requirements

- Keep changes focused and explain the problem they solve.
- Do not add credentials, tokens, private URLs, customer data, or production logs.
- Do not connect the public demo to production services.
- Use synthetic data in examples.
- Identify third-party assets and confirm their licenses before inclusion.
- Keep the demo usable without a build step or external JavaScript.

By intentionally submitting a contribution for inclusion, you agree that it is offered under the Apache License 2.0 for this community package, unless you clearly state otherwise at the time of submission.
