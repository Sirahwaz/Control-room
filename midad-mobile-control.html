واجهة خفيفة للوصول إلى البحث المجاني، فرص الدخل، تقارير الأدلة والتشغيل. لا تحتاج جهاز كمبيوتر أو مفتاح API داخل الصفحة.

قراءة عامة فقطبدون رصيد TinyFishبدون توقيع مالي

1 — الأولوية: الدخل الفعلي

الوضع الذي تم التحقق منه في 20 أكتوبر 2026: أربع فواتير/طلبات قديمة ملغاة، ولا توجد دفعة مؤكدة. لذلك نسجل «دخل = صفر مؤكد حتى يثبت القبض»، ولا نحسب الفرص أو الفواتير كإيراد.

فتح متجر MIDAD الخدمات الحالية وخدمة تشخيص مسار الدفع بقيمة 5 USDC فحص كتالوج checkout للقراءة فقط يعرض المنتجات والإصدار؛ لا ينشئ فاتورة المهام العامة في Taskmarket افحص تاريخ الانتهاء والشروط والمنافسة قبل بدء العمل

2 — وكيل المتصفح المجاني / Free Browser Agent

يجمع نصوص الصفحات العامة وبصمات SHA-256 وحالة HTTP والوقت؛ وقد ينشئ لقطة شاشة محلية لتقرير النص، وليست لقطة للموقع الأصلي. لا يتصفح Chromium مواقع خارجية. لا يسجل الدخول أو ينقر لإرسال أعمال أو يوقع معاملات.

مراجعة PR #73 التغييرات معزولة؛ الدمج ينتظر فحوص CI اختبارات الوكيل GitHub sign-in مطلوب للتشغيل اليدوي تشغيل جمع الأدلة يتاح بعد دمج workflow إلى main الكود والإعدادات المصادر والحدود الأمنية

3 — سجل الاستمرارية والتشخيص

آخر نقطة مرجعية: مسار midad_public_checkout نُشر بالإصدار 18 بعد حفظ نسخة الرجوع؛ صفحة المتجر في GitHub main تحتوي بطاقة الخدمة الجديدة. ما زال فحص العرض الفعلي على GitHub Pages قيد الانتظار.

نسخ الرجوع والتوثيق المستودع الخاص؛ يحتاج صلاحية دخول سجل CI / Actions تحقق من حالة الاختبارات قبل الدمج مستودع Control Room لوحة Supabase لا تنشر مفاتيح أو بيانات حساسة

قواعد التشغيل

  • الأولوية: دليل رسمي → تحقق الاستحقاق والمنطقة وKYC → حساب صافي العائد → ثم اختيار العمل.
  • الفرصة المكتشفة أو العمل المنجز لا يعني أن المكافأة صُرفت. لا نسجل دخلًا إلا بإثبات تسوية.
  • لا تسجيلات مكررة، لا اشتراكات مدفوعة، ولا أي شحن أدوات.
  • المحافظ للاستقبال والمراقبة فقط؛ التحويل والسحب والتوقيع والمعاملات الحية تبقى معطّلة.
  • التشغيل التلقائي يعمل فقط بعد وجود workflow على main؛ هذه الصفحة نفسها لا تملك صلاحية تشغيل عمل خلفي.
